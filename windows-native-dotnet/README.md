# اشک قلم — نسخهٔ بومی Windows / WPF

این نسخه، برنامهٔ دسکتاپ بومی است؛ رابط کاربری آن WPF است و برای نمایش صفحات از Electron، Chromium یا WebView استفاده نمی‌کند. خروجی مستقل Windows x64 در GitHub Actions ساخته می‌شود.

## امکاناتی که در نسخهٔ اجرایی محلی کار می‌کنند
- ثبت، ویرایش و حذف مشتری؛ حذف مشتری دارای سابقهٔ فاکتور مسدود است.
- ثبت، ویرایش و نگهداری کالای انبار؛ ورود موجودی و جلوگیری از صدور فاکتور بیش از موجودی.
- صدور فاکتور چندقلمی، محاسبهٔ مبلغ، مالیات واردشده و جمع کل با نوع عددی decimal.
- ثبت دریافت جزئی/کامل، محاسبهٔ مانده و جلوگیری از دریافت بیش از مانده.
- ثبت هزینه و گزارش خلاصهٔ فروش، دریافت‌ها، مطالبات و هزینه‌ها.
- کدینگ محلی حساب‌ها، ثبت دستی سند حسابداری دوبل (یک بدهکار/یک بستانکار)، دفتر روزنامه، تراز آزمایشی و خروجی CSV برای دفتر و تراز؛ این ماژول هنوز به فاکتورها و دریافت‌ها خودکار سند حسابداری وصل نیست.
- لغو فاکتور بدون دریافت و برگشت موجودی؛ فاکتور دارای دریافت را نمی‌توان با این عملیات لغو کرد.
- چاپ فاکتور از چاپگر انتخابی Windows و خروجی CSV با کدگذاری UTF-8.
- ذخیرهٔ خودکار محلی با DPAPI ویندوز برای حساب کاربری جاری؛ فایل داده در مسیر `%LOCALAPPDATA%\AshkeGhalam\WindowsNative\accounting-data.dat`.
- پشتیبان قابل انتقال با رمز انتخابی کاربر: AES-256-GCM و PBKDF2-SHA256؛ بازیابی قبل از جایگزینی، ساختار و صحت رمزنگاری را بررسی می‌کند.
- ورودی اعداد فارسی و عربی.

## راه‌اندازی سریع
۱. فایل ZIP مربوط به artifact را از بخش Artifacts اجرای موفق workflow دانلود و در یک پوشهٔ محلی استخراج کنید.
۲. فایل `AshkeGhalam.Windows.exe` را اجرا کنید. برای این خروجی self-contained نصب جداگانهٔ .NET لازم نیست.
۳. به‌ترتیب از بخش «مشتریان»، مشتری و از «کالا و انبار»، کالا و موجودی اولیه بسازید؛ سپس از «فاکتورها» فاکتور صادر کنید.
۴. قبل از استفاده از اطلاعات واقعی، یک فایل پشتیبان بسازید و بازیابی آن را در یک نسخهٔ آزمایشی جداگانه امتحان کنید.
۵. پشتیبان‌گیری رمزگذاری‌شده رمز حداقل ۱۲ نویسه می‌خواهد. اگر رمز فراموش شود، بازیابی آن ممکن نیست.

## مرزهای مهم نسخهٔ فعلی
این برنامه در حال حاضر یک **نسخهٔ عملیاتی محلی برای استفادهٔ محدود** است، نه جایگزین کامل همهٔ قابلیت‌های سامانهٔ فعلی. ورود و مجوزهای سرور، فعال‌سازی/ابطال لایسنس، همگام‌سازی ابری، چندکاربره/LAN، تطبیق بانکی واقعی، مالیات و اتصال‌های تجاری، امضای دیجیتال و مهاجرت خودکار داده از نسخهٔ فعلی هنوز در WPF پیاده‌سازی نشده‌اند. دفتر دوبل فعلی فقط ثبت دستی یک بدهکار/یک بستانکار و تراز ساده را پوشش می‌دهد؛ دوره‌بندی/قفل سال مالی و ثبت خودکار اسناد از عملیات روزمره منتقل نشده است. اطلاعات این نسخه خودکار با وب یا Electron همگام نمی‌شوند.

مبالغ بر اساس واحد پولی که خودتان وارد می‌کنید محاسبه می‌شوند؛ در تمام رکوردها یک واحد ثابت نگه دارید و نرخ مالیات را مطابق وضعیت قانونی و نیاز خود تعیین کنید. این نسخه هنوز از نظر تطابق کامل با موتور مالی نسخهٔ قدیمی تأیید نشده است؛ تا پیش از مقایسهٔ گزارش‌ها، نسخهٔ قبلی و بک‌آپ مستقل خود را حفظ کنید.

این خروجی بدون امضای تجاری Authenticode منتشر می‌شود و ممکن است Windows SmartScreen هشدار نشان دهد. فایل EXE و داده‌های محلی با فایل پشتیبان متفاوت‌اند؛ پشتیبان‌ها را جداگانه و در بیش از یک محل امن نگه دارید.

## ساخت از سورس
پیش‌نیاز: .NET 10 SDK و workload دسکتاپ Windows.

    dotnet restore windows-native-dotnet/tests/AshkeGhalam.Windows.Tests.csproj
    dotnet build windows-native-dotnet/src/AshkeGhalam.Windows/AshkeGhalam.Windows.csproj -c Release
    dotnet test windows-native-dotnet/tests/AshkeGhalam.Windows.Tests.csproj -c Release
    dotnet publish windows-native-dotnet/src/AshkeGhalam.Windows/AshkeGhalam.Windows.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o ./artifacts/windows

گزارش ممیزی و مرزهای مهاجرت در [AUDIT.md](AUDIT.md) و معماری پیشنهادی در [ARCHITECTURE.md](ARCHITECTURE.md) نگهداری می‌شوند.
