# پیش‌نمایش مرورگری اشک قلم

این بسته برای بررسی رابط کاربری در مرورگر و جدا از سرور اصلی ساخته می‌شود.

## اجرای سریع
1. از بخش **Actions** در GitHub، خروجی **AshkeGhalam-Browser-Preview** را دانلود کنید.
2. فایل ZIP را در یک پوشه استخراج کنید.
3. روی `Preview-Browser.bat` دوبار کلیک کنید.
4. مرورگر روی `http://127.0.0.1:4173` باز می‌شود. برای بستن محیط، پنجرهٔ سیاه را ببندید.

**پیش‌نیاز:** Node.js نسخهٔ ۲۰ یا جدیدتر. برای ساختن پیش‌نمایش از کد منبع، علاوه بر آن Bun لازم است؛ فایل BAT خودش فرایند ساخت را اجرا می‌کند.

## حالت ایزوله
- ارتباط با API و سرور اصلی غیرفعال است؛ درخواست‌های شبکه فقط به همین رایانه محدود می‌شوند.
- اطلاعاتی که وارد می‌کنید صرفاً در ذخیره‌ساز همین مرورگر می‌مانند؛ از اطلاعات واقعی مشتریان استفاده نکنید.
- این محیط برای بازبینی رابط و گردش کار است، نه تأیید نهایی امنیت یا عملکرد سرور.
- برای حذف داده‌های آزمایشی، اطلاعات سایت `127.0.0.1:4173` را از تنظیمات مرورگر پاک کنید.

## بازسازی از منبع
از ریشهٔ مخزن، `Preview-Browser.bat` را اجرا کنید. اسکریپت وابستگی‌های قفل‌شده را نصب می‌کند، نسخهٔ مرورگریِ آفلاین را می‌سازد و روی آدرس محلی بالا می‌آورد.
