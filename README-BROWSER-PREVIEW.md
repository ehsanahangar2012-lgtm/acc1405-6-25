# پیش‌نمایش رابط اشک قلم بدون دانلود EXE

## محیط مرورگری اختصاصی در GitHub Codespaces

برای تست UI نسخهٔ بومی ویندوز، بدون دانلود EXE یا ZIP، Codespaces محیطی خصوصی با مرورگر داخلی باز می‌کند. این محیط فقط ظاهر و گردش کار آزمایشی است؛ برنامهٔ اصلی همچنان WPF بومی و داده‌های این پیش‌نمایش از سرور اصلی جدا هستند.

1. شاخهٔ `feature/windows-native-dotnet` را در GitHub باز کنید.
2. از دکمهٔ **Code → Codespaces → Create codespace on feature/windows-native-dotnet** استفاده کنید.
3. منتظر آماده‌شدن محیط بمانید. پیکربندی `.devcontainer` سرور پیش‌نمایش را خودکار روی پورت `4173` اجرا می‌کند و مرورگر را باز می‌کند. اگر خودکار باز نشد، از تب **Ports** روی پورت `4173` کلیک کنید.
4. فایل `public/native-windows-preview/index.html` را ویرایش کنید؛ با ذخیرهٔ فایل، پیش‌نمایش در مرورگر هر ۲۰ ثانیه تغییر را بررسی و در صورت نیاز بازخوانی می‌کند.

پورت به‌طور پیش‌فرض **Private** است و Codespaces فقط به کاربران مجاز مخزن دسترسی می‌دهد. این پیش‌نمایش به API یا سرور اصلی وصل نمی‌شود.

## موارد قابل آزمایش

منوی سمت راست، اسکرول صفحه و جدول‌ها، جست‌وجو و فیلتر، ثبت سریع اشخاص و کالا با کد پیشنهادی خودکار، صدور فاکتور چندقلمی، محاسبهٔ جمع و تخفیف و مالیات، پیش‌نمایش فاکتور و چاپ/ذخیره PDF.

**توجه:** این UI مرورگری صرفاً محیط بازبینی طراحی است؛ معادل بیلد نهایی WPF نیست و داده‌های آن در `localStorage` مرورگر همان Codespace باقی می‌مانند. از اطلاعات واقعی مشتری استفاده نکنید. بازنشانی داده‌های نمونه از دکمهٔ بالای صفحه امکان‌پذیر است.

## بیلد واقعی ویندوز

بیلد مستقل WPF، آزمون‌ها و تست شروع EXE همچنان با گردش ساخت ویندوزی در GitHub Actions انجام می‌شوند:
https://github.com/ehsanahangar2012-lgtm/acc1405-6-25/actions

برای استفاده از Codespaces باید دسترسی و سهمیهٔ حساب GitHub شما اجازهٔ ساخت Codespace بدهد. اگر Codespaces در حساب در دسترس نیست، راه دیگر اجرای `Preview-Browser.bat` روی رایانهٔ خود با Node.js و Bun است.
