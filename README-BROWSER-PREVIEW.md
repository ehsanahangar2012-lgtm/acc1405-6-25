# پیش‌نمایش مرورگری اشک قلم

این بسته برای بررسی رابط کاربری در مرورگر و جدا از سرور اصلی ساخته می‌شود.

## اجرای سریع
1. از بخش **Actions** در GitHub، خروجی **AshkeGhalam-Browser-Preview** را دانلود کنید.
2. فایل ZIP را در یک پوشه استخراج کنید.
3. روی `Preview-Browser.bat` دوبار کلیک کنید.
4. مرورگر روی `http://127.0.0.1:4173` باز می‌شود. برای بستن محیط، پنجرهٔ سیاه را ببندید.

**پیش‌نیاز:** Node.js نسخهٔ ۲۰ یا جدیدتر. برای ساختن پیش‌نمایش از کد منبع، علاوه بر آن Bun لازم است؛ فایل BAT خودش فرایند ساخت را اجرا می‌کند.

## پیش‌نمایش آنلاین رابط نسخهٔ بومی ویندوز

برای بررسی چیدمان و تعاملات UI بدون دانلود EXE، صفحهٔ آزمایشی زیر در مرورگر باز می‌شود:

`https://ehsanahangar2012-lgtm.github.io/acc1405-6-25/native-windows-preview/`

در این صفحه منوی سمت راست، جست‌وجو و جدول‌های قابل اسکرول، ثبت سریع اشخاص و کالا با کد خودکار، ساخت فاکتور چندقلمی، محاسبه جمع‌ها و پیش‌نمایش فاکتور قابل آزمون است. اطلاعات فقط در `localStorage` همان مرورگر و روی همان دستگاه آزمایشی ذخیره می‌شوند و به سرور یا EXE ارسال نمی‌شوند.

**مهم:** این صفحه پیش‌نمایش تعاملی ظاهر و گردش کار است؛ برنامهٔ نهایی همچنان WPF بومی است. پس از هر تغییر در صفحه، GitHub Actions دوباره سایت را منتشر می‌کند و نسخهٔ باز هر ۲۰ ثانیه انتشار جدید را بررسی می‌کند. بیلد و آزمون‌های .NET/WPF همچنان در گردش ساخت مستقل ویندوز اجرا می‌شوند.

## حالت ایزوله
- ارتباط با API و سرور اصلی غیرفعال است؛ درخواست‌های شبکه فقط به همین رایانه محدود می‌شوند.
- اطلاعاتی که وارد می‌کنید صرفاً در ذخیره‌ساز همین مرورگر می‌مانند؛ از اطلاعات واقعی مشتریان استفاده نکنید.
- این محیط برای بازبینی رابط و گردش کار است، نه تأیید نهایی امنیت یا عملکرد سرور.
- برای حذف داده‌های آزمایشی، اطلاعات سایت `127.0.0.1:4173` را از تنظیمات مرورگر پاک کنید.

## بازسازی از منبع
از ریشهٔ مخزن، `Preview-Browser.bat` را اجرا کنید. اسکریپت وابستگی‌های قفل‌شده را نصب می‌کند، نسخهٔ مرورگریِ آفلاین را می‌سازد و روی آدرس محلی بالا می‌آورد.


## پیش‌نمایش آنلاین با به‌روزرسانی خودکار
نشانی پیش‌نمایش عمومی:
`https://ehsanahangar2012-lgtm.github.io/acc1405-6-25/`

پس از ثبت تغییر جدید در شاخهٔ `fix/core-data-integrity)، GitHub Actions نسخهٔ ایزوله را دوباره منتشر می‌کند. صفحهٔ باز هر ۲۰ ثانیه نسخهٔ جدید را بررسی کرده و در صورت انتشار، خودکار بارگذاری مجدد می‌شود. اطلاعات این نسخه در حافظهٔ مرورگر هر بازدیدکننده می‌ماند و سیاست امنیتی محتوا ارتباط با API خارجی را مسدود می‌کند.

اگر اولین انتشار به دلیل فعال نبودن GitHub Pages شکست خورد، در مخزن به **Settings → Pages → Build and deployment → Source** بروید و **GitHub Actions** را انتخاب کنید. این تنظیم فقط یک بار لازم است.
