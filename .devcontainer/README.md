# پیش‌نمایش خصوصی رابط بومی ویندوز

این پیش‌نمایش یک نمونهٔ مرورگری مستقل برای آزمودن ظاهر و گردش کار WPF است؛ برنامهٔ WPF یا WebView نیست و به سرور حسابداری/داده‌های واقعی وصل نمی‌شود. اطلاعات نمونه فقط در `localStorage` همان مرورگر ذخیره می‌شوند.

## راه‌اندازی یک‌باره

1. در مخزن خصوصی، از **Code → Codespaces → Create codespace** شاخهٔ `feature/windows-native-dotnet` را انتخاب کنید.
2. با اجرای Codespace، اسکریپت شروع، سرور خصوصی پیش‌نمایش روی پورت `4173` را خودکار بالا می‌آورد و مرورگر را باز می‌کند.
3. پورت `4173` روی حالت **Private** باقی می‌ماند. در پنل **Ports** می‌توانید **Open in Browser** را بزنید.
4. مسیر پایدار داخل همان Codespace: `/native-windows-preview/` (مسیر ریشهٔ `/` نیز به همین صفحه می‌رسد).

## به‌روزرسانی

یک watcher هر ۲۰ ثانیه شاخهٔ `feature/windows-native-dotnet` را بررسی می‌کند. تنها وقتی شاخهٔ فعال همان شاخهٔ مهاجرت و پوشهٔ کاری کاملاً پاک باشد، به‌صورت fast-forward به Commit جدید می‌رود. تغییرات محلی ذخیره‌نشده یا تاریخچهٔ منشعب هرگز بازنویسی/ادغام خودکار نمی‌شوند. صفحهٔ باز در مرورگر، تغییر نسخه را بررسی کرده و پس از به‌روزرسانی فایل HTML خودکار بارگذاری مجدد می‌شود.

## حریم خصوصی و محدودیت انتشار

- مخزن خصوصی می‌ماند؛ GitHub Pages و هیچ artifact عمومی برای این پیش‌نمایش لازم نیست.
- URL میزبان Codespaces را GitHub هنگام ساخت Codespace تولید می‌کند؛ از طریق API در دسترس این نشست نمی‌توان آن URL را از قبل ایجاد یا تأیید کرد. تا زمانی که Codespace را یک‌بار نسازید، URL واقعی پورت وجود ندارد.
- این صفحه فقط برای داده‌های ساختگی است. اطلاعات مشتری، رسید لایسنس یا اسرار را وارد نکنید.
- این صفحهٔ آزمایشی جایگزین برنامهٔ بومی WPF نیست و وضعیت قابلیت‌های WPF را اثبات نمی‌کند.
