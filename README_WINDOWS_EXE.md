# راهنمای ساخت نرم‌افزار نصبی ویندوز اشک قلم (AshkeGhalam NSIS Setup)

این مستند راهنمای کامل ساخت، استقرار، به‌روزرسانی و مدیریت دیتابیس نرم‌افزار حسابداری **اشک قلم (AshkeGhalam)** به عنوان نرم‌افزار نصبی استاندارد ویندوز (`AshkeGhalam-Setup-16.11.0.exe`) است.

---

## ۱. معماری سیستم و تفکیک فایل‌های برنامه از دیتابیس (Best Practice)

در نرم‌افزارهای حسابداری ویندوز، **جداسازی کامل فایل‌های اجرایی از داده‌های کاربر** یک ضرورت حیاتی است:

1. **فایل‌های باینری و برنامه (Application Binaries):**
   - **مسیر پیش‌فرض:** `C:\Program Files\AshkeGhalam` (یا مسیر انتخابی دلخواه کاربر هنگام نصب، مثل `D:\Software\AshkeGhalam`).
   - این پوشه فقط شامل فایل‌های اجرایی (`.exe`, `.asar`, کتابخانه‌ها) است و **فقط‌خواندنی (Read-Only)** در نظر گرفته می‌شود.
   - هنگام آپدیت یا نصب نسخه جدید، محتوای این پوشه با فایل‌های نسخه جدید جایگزین می‌شود.

2. **دیتابیس، تنظیمات و داده‌های مالی کاربر (User Database & Settings):**
   - **مسیر استاندارد ویندوز:** `%APPDATA%\AshkeGhalam` (معادل `C:\Users\<UserName>\AppData\Roaming\AshkeGhalam`).
   - تمام جداول حسابداری IndexedDB، اسناد مالی، توکن‌ها، امضاهای دیجیتال، فایل `app-config.json` و مخزن کلیدهای امن (`.secure_vault.dat`) در این مسیر ذخیره می‌شوند.
   - **امنیت در آپدیت:** نصب نسخه جدید (`Upgrade`) هرگز این پوشه را تغییر نمی‌دهد یا پاک نمی‌کند.
   - **امنیت در حذف نصب (`Uninstall`):** با تنظیم `deleteAppDataOnUninstall: false` در NSIS، در صورت حذف برنامه توسط کاربر، دیتابیس‌های مالی و بک‌آپ‌ها در سیستم باقی می‌مانند تا از نابودی اطلاعات حسابداری جلوگیری شود.

## ۲. پیش‌نیازها و پکیج‌های مورد نیاز

برای ساخت فایل نصبی در محیط ویندوز یا سرور CI/CD، پکیج‌های زیر استفاده می‌شوند:

- **Node.js:** نسخه 18 یا بالاتر
- **Electron:** موتور رندرینگ دسکتاپ
- **Electron-Builder:** ابزار ساخت پکیج و نصاب NSIS ویندوز

### دستور نصب وابستگی‌ها (یکبار در پوشه پروژه):
```bash
npm install
```

---

## ۳. دستورات ساخت بیلد ویندوز (Build Commands)

در ریشه پروژه دستورات زیر قابل اجرا هستند:

### الف) ساخت مستقیم فایل نصبی استاندارد (پیشنهادی - خروجی Setup):
```bash
npm run build:installer
```
یا با دستور جامع:
```bash
npm run build:exe
```

### ب) ساخت خروجی پرتابل (بدون نیاز به نصب):
```bash
npm run build:portable
```

### ج) ساخت هر دو خروجی نصبی و پرتابل به صورت همزمان:
```bash
npm run build:all
```

## ۴. مسیر دقیق فایل خروجی تولیدشده

پس از اتمام بیلد، در پوشه `dist_electron` فایل‌های زیر قرار می‌گیرند:

```text
📁 dist_electron/
├── 📄 AshkeGhalam-Setup-16.11.0.exe      <-- فایل نصبی استاندارد برای مشتریان (NSIS Installer)
├── 📄 AshkeGhalam-Setup-16.11.0.exe.blockmap
├── 📄 AshkeGhalam-Portable-16.11.0.exe   <-- نسخه پرتابل (در صورت بیلد پرتابل)
└── 📁 win-unpacked/                       <-- پوشه تست مستقیم فایل باینری
```

## ۵. امکانات و مشخصات Installer تولیدشده

- **نام محصول:** `AshkeGhalam`
- **شناسه برنامه (AppID):** `ir.ashkghalam.acc`
- **نسخه:** `16.11.0`
- **امکان انتخاب مسیر نصب دلخواه:** دارد (کاربر می‌تواند درایو C، D یا هر مسیر دیگری را انتخاب کند).
- **شورت‌کات دسکتاپ (Desktop Shortcut):** به صورت خودکار ایجاد می‌شود.
- **شورت‌کات منوی استارت (Start Menu):** ایجاد پوشه AshkeGhalam در استارت منو.
- **حذف نصب استاندارد (Uninstaller):** ثبت در `Add or Remove Programs` ویندوز با حذف کامل فایل‌های اجرایی بدون دستکاری داده‌های مالی.
- **سازگاری با UAC ویندوز:** بدون خطای دسترسی یا مسدودسازی.

## ۶. سناریوهای تست و اعتبارسنجی (Testing & Verification)

### تست ۱: نصب بر روی ویندوز خام و تمیز
1. فایل `AshkeGhalam-Setup-16.11.0.exe` را در یک سیستم ویندوز تمیز یا ماشین مجازی اجرا کنید.
2. مراحل نصب را با انتخاب مسیر پیش‌فرض یا دلخواه پیش ببرید.
3. برنامه را اجرا کنید و چند سند حسابداری و مشتری ثبت نمایید.
4. مسیر `%APPDATA%\AshkeGhalam\IndexedDB` را بررسی کنید و اطمینان حاصل کنید داده‌ها ذخیره شده‌اند.

### تست ۲: ارتقا (Upgrade) از نسخه 16.11.0 به نسخه‌های بعدی
1. در فایل `package.json` نسخه برنامه را به عنوان مثال به `16.12.0` افزایش دهید.
2. با دستور `npm run build:installer` فایل نصبی جدید `AshkeGhalam-Setup-16.12.0.exe` را تولید کنید.
3. بدون حذف نسخه قبلی، فایل نصبی جدید را اجرا و نصب کنید.
4. پس از باز شدن برنامه، بررسی کنید که تمامی اسناد ثبت‌شده، فاکتورها، مانده‌حساب‌ها و تنظیمات لایسنس دست‌نخورده باقی مانده‌اند.

### تست ۳: رفتار حذف نصب (Uninstall)
1. از منوی تنظیمات ویندوز (Installed Apps) برنامه `AshkeGhalam` را Uninstall کنید.
2. پوشه نصب در `Program Files` یا مسیر انتخابی پاک می‌شود.
3. شورت‌کات‌های دسکتاپ و استارت منو حذف می‌شوند.
4. مسیر `%APPDATA%\AshkeGhalam` همچنان باقی مانده است، تا در صورت نصب مجدد در آینده، دیتابیس مالی مشتری بازیابی شود.
